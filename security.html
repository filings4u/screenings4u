Section 13 // Infrastructure Architecture

Enterprise Security Is Part of the Product.

Sensitive workforce testing data requires disciplined access control, encryption, auditability, and data governance. Screenings4U implements multi-tenant data isolation and authorization at the database layer using strict row-level policies.

DATA SEPARATION

Row-Level Security (RLS)

Tenant isolation rules are strictly enforced at the database layer rather than relying on frontend JavaScript checks. Records remain restricted by tenant ID.

CRYPTO CONTROLS

Encryption Criteria

Workforce identity strings, medical records, and drug testing results undergo strict encryption protocol parameters both in transit and at rest.

IMMUTABLE LOGS

Administrative Audit Trail

System changes, permission mutations, result access logs, and data exports generate unalterable records capturing user IDs, timestamps, and IP addresses.
